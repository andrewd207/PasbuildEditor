:icons: font

A keyboard-driven, full-screen terminal editor for https://github.com/graemeg/PasBuild[PasBuild] `project.xml` files, written in Free Pascal.

== What it does

https://github.com/graemeg/PasBuild[PasBuild] is a Maven-inspired build tool for Free Pascal projects. Its `project.xml` files describe build settings, unit paths, profiles, module dependencies, and more. Editing them by hand is tedious and error-prone. PasbuildEditor provides a safe, structured UI for doing it from the terminal.

== Features

* Works with application, library, and POM (multi-module aggregator) project types.
* Edit identity fields: name, version, author, license, description, URLs.
* Manage build profiles with per-profile defines and compiler options.
* Configure source/output directories, unit paths, include paths, and defines.
* Add, remove, and manage external package dependencies and sibling module dependencies.
* Manage POM child modules: enable/disable, create new, scan folder, or add by path.
* Run pasbuild goals (compile, test, package, install, …) and stream live output.
* Breadcrumb navigation — drill into sub-projects and back out with the left arrow.
* Auto-save on Ctrl-X; explicit save on Ctrl-S.

== Building

Requires Free Pascal 3.x and PasBuild.

[source,shell]
----
pasbuild compile
----

The binary is written to `pasbuildeditor/target/pb-editor`.

== Usage

[source,shell]
----
pb-editor [project.xml]
----

If no path is given the editor looks for `project.xml` in the current directory. Navigation is keyboard-driven: arrow keys move between items, Enter opens a sub-menu, Escape or Left goes back, and highlighted hotkeys jump directly to items.
