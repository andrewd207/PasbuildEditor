= TermUI
Andrew Haines <andrewd207@github>
:toc: left
:icons: font

A small, self-contained Free Pascal library for building keyboard-driven full-screen terminal UIs. It provides a double-buffered terminal abstraction, a menu widget, an inline line editor, and a recursive file/directory picker.

== Units

[cols="1,3"]
|===
| `TermUI.Terminal`          | Double-buffered terminal base class (`TTerminal`). Platform implementations register themselves via `RegisterTerminalFactory`.
| `TermUI.Menu`              | Menu widget, inline editor, confirmation prompt, and drawing helpers.
| `TermUI.PathPicker`        | Full-screen recursive path picker.
|===

A platform unit (`TermUI.Terminal.Platform`) must be compiled into the *application*, not the library. The Unix implementation lives in `src/platform/unix/`.

== Setup

In your application's `uses` clause include the platform unit so the factory is registered before `Term` is first accessed:

[source,pascal]
----
uses
  TermUI.Terminal,
  TermUI.Terminal.Platform,  { registers the platform implementation }
  TermUI.Menu;
----

Set `AppTitle` and `AppVersion` before entering raw mode:

[source,pascal]
----
AppTitle   := 'MyApp';
AppVersion := '1.0';
Term.EnableRawMode;
{ ... UI loop ... }
Term.DisableRawMode;
----

`Term` is a global `TTerminal` instance created automatically when the unit is initialised.

== TMenu

Build a menu by creating a `TMenu`, adding items, then calling `Run`. `Run` blocks until the user selects an item, presses Escape/Left (returns `nil`), or presses a global signal key.

[source,pascal]
----
var
  Menu: TMenu;
  Sel:  TMenuItem;
begin
  Menu := TMenu.Create('My Menu');
  try
    Menu.AddHeader('Section');
    Menu.Add(TMenuItem.Create('First option',  @DoFirst,  '', 'F'));
    Menu.Add(TMenuItem.Create('Second option', @DoSecond, '', 'S'));
    Menu.AddSeparator;
    Menu.Add(TMenuItem.Create('Quit', nil, '', 'Q'));
    Sel := Menu.Run;
    if Assigned(Sel) and Assigned(Sel.Action) then
      Sel.Action(nil);
  finally
    Menu.Free;
  end;
end;
----

=== TMenuItem constructors

[cols="1,3"]
|===
| `Create(Label, Action, Value, Hotkey, Hint)` | Standard item. All parameters after `Label` are optional.
| `CreateEmbeddedHotkey(Label, Action, Value, Hint)` | Derives the hotkey from the first `&` in the label string (e.g. `'&Quit'` → hotkey `Q`, displayed label `Quit`). The `&` is stripped before display.
| `CreateHeader(Label)` | Non-selectable section heading.
| `CreateSeparator` | Non-selectable horizontal rule.
|===

=== TMenuItem fields

[cols="1,3"]
|===
| `Value`     | Secondary text rendered right-aligned in green.
| `Hint`      | Gray suffix appended after the label (for header items).
| `Desc`      | One-line description shown in the status bar when the item is highlighted.
| `Hotkey`    | Single character that jumps to and selects this item directly.
| `Enabled`   | When `False` the item is skipped during navigation (default `True`).
| `DimValue`  | Render `Value` in grey (e.g. `(none)` placeholders).
| `DimItem`   | Render the entire row in grey (e.g. inactive modules).
| `MarkOld`   | Render `Value` in yellow (e.g. outdated version numbers).
|===

=== TMenu API

[cols="1,3"]
|===
| `Add(Item)`             | Append a selectable item.
| `AddHeader(Label)`      | Append a non-selectable section heading.
| `AddSeparator`          | Append a horizontal rule.
| `SelectByLabel(Label)`  | Move the selection to the first item whose label matches.
| `Run`                   | Draw the menu and block until the user acts; returns the selected `TMenuItem` or `nil` on back/quit.
| `SelectedRow`           | Screen row (1-based) of the currently highlighted item; useful for positioning an inline editor.
|===

After `Run` returns, check:

[cols="1,3"]
|===
| `ExitedLeft`    | `True` when the left-arrow was used to go back (vs. Escape).
| `DeletePressed` | `True` when Del was pressed on the current selection.
| `F1Pressed`     | `True` when F1 was pressed.
| `UnhandledChar` | Set to the typed character when a keystroke was not consumed; `#0` otherwise.
|===

=== Keyboard navigation

[cols="1,3"]
|===
| Up / Down          | Move selection one item.
| Page Up / Page Down | Move selection one visible page.
| Home / End         | Jump to first / last selectable item.
| Enter / Right      | Confirm selection.
| Escape             | Exit (`ExitedLeft = False`).
| Left               | Exit (`ExitedLeft = True`).
| Delete             | Signal deletion (`DeletePressed = True`).
| F1                 | Signal help (`F1Pressed = True`).
| Printable char     | Match a hotkey, or set `UnhandledChar` and exit.
|===

Incremental search is built in: typing any printable character that does not match a hotkey is returned to the caller via `UnhandledChar`.

== EditLine

Inline single-line text editor. Opens at the selected menu row (or vertically centred if `ARow` is 0).

[source,pascal]
----
var S: string;
begin
  S := CurrentValue;
  if EditLine('New name', S, S) then
    { user confirmed — S holds the new value };
end;
----

The editor supports Home/End, Left/Right, Ctrl+Left/Ctrl+Right (word jump), Backspace, Delete, and character insertion. Escape cancels (returns `False`); Enter confirms (returns `True`).

== Confirm

[source,pascal]
----
if Confirm('Delete this profile?') then
  { ... };
----

Default answer is No. Pass `True` as the second argument to make Yes the default. Enter accepts the default; `Y`/`N` override it; Escape always returns `False`.

== ShowStatusMsg

Writes an ephemeral message at the bottom of the screen and waits for a key.

[source,pascal]
----
ShowStatusMsg('Saved.', clBrightGreen);
ShowStatusMsg('Error: file not found.', clRed);
----

== RunPathPicker

Full-screen file/directory browser with an incremental filter. Returns `True` when the user accepts a selection; the chosen path is written back via `APath`.

[source,pascal]
----
var P: string;
begin
  P := '/home/user';
  if RunPathPicker('/home/user', 'Select project directory', True, P) then
    { P now holds the chosen directory };
end;
----

Pass `ADirsOnly = False` to allow file selection as well.

The top row is a filter box. Typing narrows the list; pressing Up/Down moves focus into the file list. Pressing Enter on a list entry copies it back to the filter box. Pressing Enter in the filter box accepts the current text as the result — if the path does not exist the user is prompted to create it. Hidden entries (names starting with `.`) are only shown when the filter itself starts with `.`.

== Global Signals

Four boolean globals are set by `TMenu.Run` and `RunPathPicker` in response to special key chords and are intended to be polled by the application's main loop:

[cols="1,1,3"]
|===
| Variable          | Key     | Meaning
| `GQuitRequested`  | Esc / Q | User wants to exit.
| `GSaveRequested`  | Ctrl-S  | User requested an explicit save.
| `GCtrlXRequested` | Ctrl-X  | User requested save-and-quit.
| `GCtrlCRequested` | Ctrl-C  | Hard interrupt.
|===

== TTerminal

`TTerminal` is an abstract double-buffered terminal. Drawing calls (e.g. `WriteStr`, `GotoXY`) write into a back buffer; `FlushOutput` diffs it against the front buffer and emits only changed cells, then swaps. This eliminates most flicker.

Subclasses must implement `Width`, `Height`, `EnableRawMode`, `DisableRawMode`, `ReadKey`, `ReadKeyTimeout`, `HideCursor`, and `ShowCursor`. Override `HasResized` to detect terminal resize events (SIGWINCH); `TMenu.Run` and `RunPathPicker` call it after every keypress and redraw when it returns `True`.

`EnterAltScreen` / `ExitAltScreen` are provided as no-ops in the base class; platform implementations may override them to switch to the terminal's alternate screen buffer.

`ReadKeyTimeout` is a non-blocking variant of `ReadKey`:

[source,pascal]
----
var K: TKeyEvent;
begin
  if Term.ReadKeyTimeout(K, 200) then
    { handle K };
end;
----

Returns `False` if no key arrived within `TimeoutMs` milliseconds.

== Drawing Helpers

[cols="1,3"]
|===
| `DrawHeader(Breadcrumb, Row)` | Renders the title bar with app name, version, and breadcrumb path.
| `DrawRule(Row, Col, Width)`   | Draws a horizontal separator line.
| `PadRight(S, Width)`          | Right-pads a string with spaces to the given width (truncates if longer).
| `JoinTruncated(List, Sep, MaxLen)` | Joins list items with a separator, appending `…` if the result exceeds `MaxLen`.
| `IsValidIdentifier(S)`        | Returns `True` if `S` is a valid Pascal identifier (letter/underscore first, then letters/digits/underscores).
|===
