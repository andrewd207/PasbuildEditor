= TermUI.Control.Editor
:toc:

== Overview

`TTextEditor` is a multi-line text editor with pluggable syntax highlighting, selection, clipboard integration, and optional word wrap.
In read-only mode the control scrolls without allowing edits.

Syntax highlighting is provided by subclassing `TTextHighlighter` and assigning an instance to `TTextEditor.Highlighter`.

== TTextHighlighter

[source,pascal]
----
TTextHighlighter = class
  constructor Create; virtual;
  procedure Prepare(ALines: TStrings); virtual;
  procedure GetSpans(ARow: Integer; const ALine: string;
    out ASpans: TTextSpanArray); virtual;
  function Name: string; virtual;
end;
----

`Prepare` is called once before the paint pass with the full document.
Use it for multi-line state (code fences, block comments, tables).

`GetSpans` is called per visible row.
Return an array of `TTextSpan` records that will be applied over the plain text.

`Name` returns the highlighter's display name (used by the registry).

=== TTextSpan

[source,pascal]
----
TTextSpan = record
  Col:       Integer;   // 0-based codepoint offset into the line
  Len:       Integer;   // codepoint length of the span
  FG:        TColor;
  BG:        TColor;
  Underline: Boolean;
end;
----

Spans may overlap; later spans in the array take precedence character by character.

=== Highlighter registry

Highlighters self-register in their unit's `initialization` section via `RegisterHighlighter`.
The editor can then look them up by file extension or name.

[source,pascal]
----
procedure RegisterHighlighter(AClass: TTextHighlighterClass;
  const AExtensions: string);   // semicolon-separated, e.g. '.pas;.pp'

function FindHighlighterForExt(const AExt: string): TTextHighlighter;
function FindHighlighterByName(const AName: string): TTextHighlighter;
procedure GetHighlighterNames(AList: TStrings);
----

== TTabMode

[source,pascal]
----
TTabMode = (tmSpaces, tmChar);
----

`tmSpaces` — pressing Tab inserts `TabWidth` space characters.
`tmChar`   — pressing Tab inserts a literal tab character.

== TSelection

[source,pascal]
----
TSelection = record
  Active:    Boolean;
  AnchorRow: Integer;   // 1-based
  AnchorCol: Integer;   // 1-based
end;
----

`Active = True` while a selection is being extended.
The selection spans from (AnchorRow, AnchorCol) to the current cursor position.

== TTextEditor

Extends <<control.adoc#,TControl>>.

[source,pascal]
----
TTextEditor = class(TControl)
  { Bulk update — suppress repaint/highlight until EndUpdate }
  procedure BeginUpdate;
  procedure EndUpdate;

  procedure Clear;
  procedure ScrollToBottom;
  procedure InsertText(const AText: string);
  procedure CopyCurrentLine;

  property Lines:                   TStrings;          // content; caller may populate directly
  property ReadOnly:                Boolean;
  property WordWrap:                Boolean;           // suppresses horizontal scroll
  property CaptureTabs:             Boolean;           // default False; True = Tab key handled by editor
  property TabMode:                 TTabMode;          // tmSpaces (default) or tmChar
  property TabWidth:                Integer;           // default 2
  property HighlightTrailingSpaces: Boolean;           // highlight trailing whitespace
  property Highlighter:             TTextHighlighter;  // not owned by the editor
  property CursorRow:               Integer;           // 1-based
  property CursorCol:               Integer;           // 1-based
  property Selection:               TSelection;        // current selection state
  property OnChange:                TNotifyEvent;
end;
----

=== Read-only key bindings

[cols="1,3"]
|===
| Key | Action

| `Up` / `Down`
| Move cursor / scroll one row

| `Left` / `Right`
| Move cursor one codepoint

| `PgUp` / `PgDn`
| Scroll one page

| `Home` / `End`
| Start / end of current line

| `Ctrl+Home`
| Jump to first line

| `Ctrl+End`
| Jump to last line
|===

=== Edit key bindings (ReadOnly = False)

All read-only bindings plus:

[cols="1,3"]
|===
| Key | Action

| `Backspace` / `Delete`
| Delete character before / at cursor

| `Enter`
| Insert new line

| `Ctrl+K`
| Kill to end of line

| `Tab` (when CaptureTabs = True)
| Insert spaces or tab char per TabMode

| Printable char
| Insert at cursor
|===

=== Selection key bindings

[cols="1,3"]
|===
| Key | Action

| `Shift+Left` / `Shift+Right`
| Extend selection one codepoint

| `Shift+Up` / `Shift+Down`
| Extend selection one row

| `Shift+Home` / `Shift+End`
| Extend selection to line start / end

| `Shift+Ctrl+Home` / `Shift+Ctrl+End`
| Extend selection to document start / end

| `Ctrl+A`
| Select all
|===

=== Clipboard key bindings

[cols="1,3"]
|===
| Key | Action

| `Ctrl+C`
| Copy selection (or current line if no selection) to clipboard

| `Ctrl+X`
| Cut selection to clipboard

| `Ctrl+V`
| Paste from clipboard at cursor

| `kcBracketedPaste`
| Bracketed paste from terminal (treated as Ctrl+V)
|===

=== Syntax highlighting

[source,pascal]
----
Editor := TTextEditor.Create;
Editor.Highlighter := TAsciiDocHighlighter.Create;
// The editor does NOT free the highlighter.
----

See <<highlighter_asciidoc.adoc#,TAsciiDocHighlighter>> for a ready-to-use example.
