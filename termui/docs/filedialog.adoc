= TermUI.Form.FileDialog
:toc:

link:index.adoc[← Index]

== Overview

`TFileDialog` is a full-filesystem file picker that supports open, save, and directory-select modes.
It renders a two-column list (name + condensed size), with live inline text filtering, hidden-file toggle, and symlink coloring.

Convenience functions `RunOpenDialog`, `RunSaveDialog`, and `RunDirDialog` are provided for one-liner usage.

== TFileDialogMode

[source,pascal]
----
TFileDialogMode = (fdOpen, fdSave, fdSelectDir);
----

== TFileDialog

Extends <<forms.adoc#,TForm>>.

[source,pascal]
----
TFileDialog = class(TForm)
  procedure SetParams(const AInitialDir: string; AMode: TFileDialogMode;
    const AInitialFilename: string = '');
  function  RunModal: Boolean;   // True = accepted

  procedure AddFilter(const AName, APattern: string);

  property FileFilter:      string;    // active glob(s), semicolon-separated; default '*'
  property WantExtensions:  Boolean;   // show extension in file list (default True)
  property Accepted:        Boolean;
  property ResultPath:      string;
end;
----

Call `SetParams` then `RunModal`, or use one of the convenience wrappers below.

== Convenience functions

[source,pascal]
----
function RunOpenDialog(const AInitialDir: string; var APath: string;
  const ATitle: string = 'Open'): Boolean;

function RunSaveDialog(const AInitialDir: string; var APath: string;
  const ATitle: string = 'Save'): Boolean;

function RunDirDialog(const AInitialDir: string; var APath: string;
  const ATitle: string = 'Select Directory'): Boolean;
----

== File list

=== Layout

----
/home/user/src          [*.pas;*.pp]
────────────────────────────────────────
..
src/
readme.adoc                         1.2K
main.pas                             34K
────────────────────────────────────────
Filename: [main.pas               ]
[*.pas;*.pp ▼]
----

* Directories are listed before files, both groups sorted alphabetically.
* Size column is right-aligned; blank for directories.
* The active filter glob is shown in brackets in the path row.
* A live inline search overlays the `..` row when the user types in the file list.

=== Condensed sizes

[cols="1,2"]
|===
| Range | Format example

| < 1 KB
| `512B`

| < 1 MB
| `1.2K`

| < 1 GB
| `34M`

| ≥ 1 GB
| `1.3G`
|===

=== Symlink coloring (Unix)

Entries with `faSymLink` in `TSearchRec.Attr` are rendered in `clBrightYellow`.

== Key bindings

=== File list focus

[cols="1,3"]
|===
| Key | Action

| `Up` / `Down`
| Move selection

| `Enter` / `Right`
| Enter directory or accept file

| `Left`
| Navigate to parent directory

| `Backspace`
| Remove last inline-filter char; if filter is empty, navigate to parent directory

| `Tab`
| Switch focus to filename field (fdOpen / fdSave)

| `H` / `h`
| Toggle hidden files

| `Escape`
| Cancel
|===

Typing any printable character appends to the live inline filter.
The filter overlay appears on the `..` row; clearing it restores normal display.

=== Filename field focus (fdOpen / fdSave)

[cols="1,3"]
|===
| Key | Action

| `Tab`
| Switch focus back to file list

| `Enter`
| Accept the typed filename

| `Escape`
| Cancel
|===

Standard <<lineeditor.adoc#,TTextEdit>> editing keys apply.

=== Filter combo focus

[cols="1,3"]
|===
| Key | Action

| `Tab`
| Switch focus back to file list

| `Enter` / `Space`
| Open filter selector drop-down

| `Escape`
| Cancel
|===

== AddFilter

[source,pascal]
----
Dialog.AddFilter('Pascal files', '*.pas;*.pp');
Dialog.AddFilter('All files',    '*');
----

Adds a named entry to the filter combo box.
The first call also sets `FileFilter` to that pattern.

== WantExtensions

When `WantExtensions` is `False`, file extensions are stripped from the display names in the list.
Default is `True`.

== FileFilter

`FileFilter` is a semicolon-separated list of globs: `*.pas;*.pp`.
Matching uses `MatchesMask` from the `Masks` unit.
Directories are always shown regardless of the filter.
