= TermUI Component Reference
:toc: left
:toclevels: 2

A terminal UI library written in Free Pascal (Object Pascal, `{$mode objfpc}{$H+}`).

== Architecture overview

All visible elements inherit from <<control.adoc#,TControl>>.
The <<application.adoc#,TApplication>> singleton owns a stack of <<forms.adoc#,TForm>> instances and runs the event loop.
Containers implement <<control.adoc#IContainer,IContainer>> (CORBA, no ref-counting) to arrange children automatically when bounds change.
