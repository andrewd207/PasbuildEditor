= TermUI.Application
:toc:

link:index.adoc[← Index]

== Overview

`TermUI.Application` provides `TApplication`, the singleton that owns the form stack, runs the event loop, and coordinates repainting.

The global instance is `Application` (declared in the unit and created in its `initialization` section).

== TDrawingChar

The `TDrawingChar` enum names every drawing character the application uses for borders, scroll bars, check boxes, and other UI chrome.
`Application.DrawingChar[dc]` returns the actual string for the current mode (Unicode or ASCII fallback).

[source,pascal]
----
TDrawingChar = (
  dcTopLeft, dcTopRight, dcBottomLeft, dcBottomRight,
  dcHorizontal, dcVertical,
  dcLeftT, dcRightT, dcTopT, dcBottomT, dcCross,
  dcUpArrow, dcDownArrow,
  dcFullBlock, dcScrollBar,
  dcLeftBracket, dcRightBracket,
  dcDropDown,
  dcChevronRight,
  dcArrowUp, dcArrowLeft, dcArrowRight, dcArrowDown,
  dcTriangleRight, dcTriangleDown,
  dcGutterBar,
  dcFocusLeft, dcFocusRight,
  dcBullet,
  dcCheckBoxEmpty, dcCheckBoxChecked,
  dcRadioEmpty, dcRadioChecked,
  dcEllipsis,
  dcProgressFull, dcProgressEmpty,
  dcClose,
  dcMenu,
  dcSeparator
);
----

`UseUnicodeBorders` (default `True` when the terminal supports it) selects between Unicode box-drawing glyphs and plain ASCII characters (`+`, `-`, `|`, etc.).

== TApplication

[source,pascal]
----
TApplication = class
  procedure Run;
  procedure ProcessMessages;
  procedure Terminate;
  procedure Resume;

  procedure PushForm(AForm: TForm);
  procedure PopForm;
  procedure ClearFormStack;
  function  ShowModal(AForm: TForm): Integer;

  { Peek management }
  procedure ShowPeek(AForm: TForm);
  procedure HidePeek(AForm: TForm);
  procedure TogglePeek(AForm: TForm);
  function  PeekVisible(AForm: TForm): Boolean;

  { Drawing helpers }
  procedure DrawChar(ADC: TDrawingChar);
  procedure RepeatChar(ADC: TDrawingChar; ACount: Integer);

  property Terminated:         Boolean;
  property ActiveForm:         TForm;
  property FormStack:          array of TForm;     // read-only view
  property OnKeyDown:          TKeyDownEvent;
  property OnIdle:             TNotifyEvent;
  property OnPostPaint:        TNotifyEvent;       // fired after every repaint
  property OnShowException:    TExceptionEvent;    // override crash display
  property HelpKey:            TKeyCode;           // default kcF1; kcNone = disable
  property UseUnicodeBorders:  Boolean;
  property DrawingChar[ADC: TDrawingChar]: string; // read-only
end;
----

== Event loop

`Run` calls `ProcessMessages` in a tight loop until `Terminated` is True.

Each `ProcessMessages` cycle:

. Calls `CheckSynchronize` (delivers <<timer.adoc#,TTimer>> and other `Synchronize` callbacks).
. Reads a key (16 ms timeout — non-blocking if no input).
. Dispatches the key or fires `OnIdle`.
. Repaints if anything was invalidated; `OnPostPaint` fires after the repaint (used by <<debug_overlay.adoc#,TDebugOverlay>>).
. Auto-pops any overlay form whose `ModalResult <> 0`.

`Resume` re-enters the loop after an external suspension (e.g. spawning a subprocess that takes over the terminal).

== Form stack

The stack is a dynamic array accessible via `FormStack`; index `N-1` is the active form.

`PushForm` adds a form to the top.
`PopForm` removes the top form.
`ClearFormStack` removes all forms (useful before switching major UI states).
`ShowModal` is equivalent to `PushForm` + spin `ProcessMessages` + `PopForm`, returning `ModalResult`.

=== Repainting with overlays

`RepaintActive` walks down the stack from the top until it finds the first non-overlay form, then paints all forms from there upward into the back buffer before a single `FlushOutput`.
This makes multiple simultaneous <<peek.adoc#,peek panels>> work without flicker.

== Help key [[HelpKey]]

When a key matching `HelpKey` (default `kcF1`) arrives and is not consumed by the active form's `DoKeyDown`, the application calls `ActiveForm.Help`, which propagates through the focused control chain.

Set `HelpKey := kcNone` to disable entirely.

== Peek management

Any <<forms.adoc#TForm,TForm>> with `Overlay = True` can be used as a peek.
Typically you use <<peek.adoc#,TPeekForm>> which sets `Overlay` automatically.

[source,pascal]
----
FHelp := TPeekForm.Create(psRight, 40, 'Help');
// show/hide on demand:
Application.TogglePeek(FHelp);
----

`ShowPeek` pushes if not already visible.
`HidePeek` removes from anywhere in the stack.
`TogglePeek` does one or the other.
`PeekVisible` returns `True` if the form is currently in the stack.

== Drawing helpers

[source,pascal]
----
Application.DrawChar(dcTopLeft);           // write one drawing char at current cursor
Application.RepeatChar(dcHorizontal, 20); // write 20 horizontal bar chars
----

These helpers read from `DrawingChar[]` internally so callers do not need to check `UseUnicodeBorders` themselves.

== Exception handling

`OnShowException` is set by <<crash_handler.adoc#,TermUI.Form.CrashHandler>> in its `initialization` to display a crash overlay dialog.
Override it before calling `Run` if you need custom error display.

== Resize handling

When the terminal is resized, `HandleResize` calls `SetBounds(1, 1, Term.Width, Term.Height)` on *every* form in the stack (not just the active one), triggering the full <<control.adoc#,DoBoundsChanged cascade>>.
<<peek.adoc#,TPeekForm>> overrides `SetBounds` to recalculate from its side and peek-size rather than accepting the full-screen bounds.
